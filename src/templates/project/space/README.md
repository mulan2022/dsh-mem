# 项目记忆

这里装**每个项目各自的记忆**。每个项目是 `projects/` 下的一个目录，
以**项目名**命名（例如 `projects/MemoryChat/`），便于在文件管理器里一眼认出。

## 装什么

| 位置 | 作用 |
| --- | --- |
| `projects/<项目名>/` | 那个项目的目标、架构、决策、待办、时间线 |
| `observations.md` | 跨项目的暂存观察（不属于任何具体项目的） |
| `log.md` | 整理（dream）的审计日志 |

项目目录由 `workspaces.yaml` 的登记 + cwd 推导，**不需要手工建**。

## 注入规则（重要）

**项目记忆不会被主动注入上下文。**

平时往上下文里注入的只有两样：

- **常驻记忆**（`../shared/instructions.md`）
- **全局共用**：身份、准则、能力画像、taste 等（`../shared/sections/`）

项目里的具体内容要 AI **主动调工具**去取：

- `mem_search` —— 跨所有空间与项目检索，结果带归属
- `mem_entity` —— 按名字翻实体页
- `mem_diff` —— 按 `[→ id]` 取某条时间线的完整改动

**为什么**：项目细节量大、而且多数时候用不上；全塞进上下文既贵又吵。
"开局只给标题，需要时再去翻"是这套设计的一贯做法。
