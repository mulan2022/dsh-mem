# 全局层

这里的东西**所有会话都会注入** —— 聊天会话和项目会话都读它。

## 装什么

| 内容 | 说明 |
| --- | --- |
| `instructions.md` | **常驻记忆**：你明确要求 AI 始终记住的条目，上限 50 条，不参与自动淘汰 |
| `soul.md` | AI 自身的设定 |
| `user.md` | 你的身份与通用偏好 |
| `rules.md` | 全局设计原则与行为准则 |
| `ability.md` | **能力画像**：代码水平、数学水平、擅长与短板 |
| `preferences.md` | **项目偏好**：工作方式、评审习惯、对工具链的取舍 |
| `stack.md` | 技术栈偏好 |

## 为什么是独立一层

`chat/` 记的是"关于你这个人"的（价值观、态度、沟通风格），
`proj/<key>/` 记的是"关于某个项目"的。

但还有些东西**两层都成立、又不属于任何具体项目**：你是谁、你希望被怎么对待、
你的通用准则、你的能力画像与工作偏好。放进任何一边都会让另一边读不到。

**能力画像和项目偏好曾经单独放在 `spaces/project/_shared/`** —— 那个位置是错的：
它们是跨项目的，而项目空间里再分一层"跨项目"，等于把同一类东西切成两个抽屉，
还会让聊天会话读不到它们。现在合并到这里。

## 与自动沉淀的区别

常驻记忆是**你主动交代**的，不算 AI 提炼的。
所以它：

- **永远在上下文里**（每次会话都注入）
- **不参与自动整理** —— 自动整理按"重复/低价值"清库时，绝不会动它
- 满 50 条时**拒绝新增并告诉你**，不会偷偷淘汰最旧的

## 怎么改它

**不要手动编辑 `instructions.md`。** 它由 AI 通过工具维护，
手工改动可能在下一次工具写入时被整段重写覆盖。

- 要添加 → 直接说「**记住**……」
- 要删除 → 说「**忘掉**……」
- 只想看看 → DSH 设置 → 记忆空间 → 全局层

---

*除 `instructions.md` 外，其余文件会被 dream 重写；手工修改前请留意。*
